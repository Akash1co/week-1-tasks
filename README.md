# HTML5 Semantics & Accessibility — Week 1, Day 1

A clean, accessible web page built as part of my internship tasks. This project focuses on writing clean semantic HTML5, making the page screen-reader friendly with ARIA, and following standard Git workflows.

---

## What I Built

- **Semantic Layout:** Used native HTML5 tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, and `<footer>`) instead of generic `<div>` soup.
- **Accessibility (A11y):** Added `aria-label` and `aria-labelledby` attributes to help screen readers navigate the structure smoothly.
- **Clean Code (0 Errors):** Tested and verified through the W3C Markup Validator with zero errors and zero warnings.
- **Basic SEO Setup:** Included essential meta tags like viewport and description for mobile responsiveness and search indexing.
